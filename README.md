## Audio MIDI Marker

This repo is a small Flask app for annotating MIDI notes against synchronized audio (and optional video).

### Data layout

The app discovers songs under:

- `/root/audio-midi-marker/data/<song-name>/`

Each `<song-name>` folder should contain:

- **Required**
  - `*.mid`
  - `*.wav` or `*.mp3`
- **Optional**
  - `*.mp4`
  - `annotation.csv` (auto-created by the UI when you start saving annotations)
  - `ai_cache/` (generated by the AI fingering helper)

### Import from pooled files

If you already have pooled files like:

- `Paganini_Op01-01_AlicanSuner_lTsRFEpD6Jg-0001-0149_cut_trim.wav`
- `Paganini_Op01-01_AlicanSuner_lTsRFEpD6Jg-0001-0149_cut_trim.mp4`
- `Paganini_Op01-01_AlicanSuner_lTsRFEpD6Jg-0001-0149_trim.mid`

You can organize them into `data/<song-name>/` folders with:

```bash
python3 /root/audio-midi-marker/organize_data.py \
  --src /mnt/hdd/violin_media_outputs/Paganini \
  --dst /root/audio-midi-marker/data \
  --mode symlink \
  --dry-run
```

Then remove `--dry-run` to actually create folders and links:

```bash
python3 /root/audio-midi-marker/organize_data.py \
  --src /mnt/hdd/violin_media_outputs/Paganini \
  --dst /root/audio-midi-marker/data \
  --mode symlink
```

Notes:

- `--mode symlink` avoids duplicating large audio/video files.
- Use `--only-base Paganini_Op01-01_AlicanSuner` to test on a single piece first.
- If both `*_trim.mid` and `*_merge.mid` exist, you can choose with `--prefer-midi trim|merge`.
